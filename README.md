# GameLanguageTranslatorAI

![Uygulama Görseli](demo.png)

GameLanguageTranslatorAI, oyun geliştiricileri için oyun içi metinleri farklı dillere çevirmeyi kolaylaştıran bir araçtır. OpenAI'nin güçlü dil modellerini kullanarak, oyun içeriğinizin hızlı ve doğru bir şekilde lokalizasyonunu sağlar.

## Özellikler

- 🎮 Oyun içi metinlerin otomatik çevirisi
- 🌐 Çoklu dil desteği
- 🤖 OpenAI GPT modelleriyle yüksek kaliteli çeviri
- 📁 JSON, CSV ve metin dosyalarıyla uyumlu
- 🧪 Test ve önizleme özellikleri

## Kurulum

### Gereksinimler

- [.NET 8 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)
- Visual Studio 2022 veya üzeri (veya uyumlu bir IDE)

### Adımlar

1. **Depoyu Klonlayın:**

   ```bash
   git clone https://github.com/erdokrmn/GameLanguageTranslatorAI.git
   cd GameLanguageTranslatorAI
   ```

2. **Projeyi Açın:**

   Visual Studio veya tercih ettiğiniz IDE ile `GameLanguageTranslatorAI.sln` dosyasını açın.

3. **Bağımlılıkları Yükleyin:**

   Gerekli NuGet paketlerini yükleyin.

4. **Uygulamayı Çalıştırın:**

   Projeyi derleyin ve çalıştırın.

## Kullanım

1. **API Anahtarınızı Ayarlayın:**

   OpenAI API anahtarınızı uygulama ayarlarına ekleyin. Nasıl alacağınızı aşağıda bulabilirsiniz.

2. **Metin Dosyasını Yükleyin:**

   Çevirmek istediğiniz metin dosyasını uygulamaya yükleyin.

3. **Hedef Dili Seçin:**

   Çeviri yapılacak dili seçin.

4. **Çeviriyi Başlatın:**

   "Çevir" butonuna tıklayarak işlemi başlatın.

5. **Sonuçları Kaydedin:**

   Çevrilen metni istediğiniz formatta kaydedin.

## OpenAI API Anahtarı Oluşturma

1. **Hesap Oluşturun:**

   [OpenAI](https://platform.openai.com/signup) sitesine giderek ücretsiz bir hesap oluşturun.

2. **API Anahtarınızı Oluşturun:**

   - [API Anahtarları Sayfası](https://platform.openai.com/account/api-keys)'na gidin.
   - "Create new secret key" butonuna tıklayın.
   - Oluşturulan anahtarı güvenli bir yerde saklayın. Bu anahtar, uygulamada OpenAI hizmetlerine erişim için kullanılacaktır.

3. **API Anahtarınızı Uygulamaya Ekleyin:**

   Uygulamanın ayarlar bölümüne API anahtarınızı girin.
